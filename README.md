# Faceplant

用原生 ARKit + Metal 复现 2018 年 Faceplant 的"脸从墙里顶出来"效果。设计文档见 [docs/技术方案.md](docs/技术方案.md)。

## 环境

- Xcode 27.2，iOS 16+ 部署目标
- `brew install xcodegen swiftlint swiftformat just`
- 首次构建需要 Metal 工具链：`xcodebuild -downloadComponent MetalToolchain`

## 常用命令

```bash
just gen      # 重新生成 Faceplant.xcodeproj（改了 project.yml 或增删文件后）
just check    # lint + 格式检查 + 真机 SDK 编译
just format   # 自动格式化
```

`Faceplant.xcodeproj` 不入库，clone 后先执行 `just gen` 生成。人脸追踪不能在模拟器上跑，运行必须用真机。打开工程后在 Signing 里选自己的 Team 即可。

## 当前阶段：M3 留言 + M4 附近通话（代码完成，待真机验收）

放置页在这一轮顺手补了三件事：已检测的平面先画成网格、放下后网格消失；桌面等水平面上脸的朝向改按屏幕上方算，不再随机；放下后可以拖动、双指旋转、双指缩放微调，调整会跟留言一起保存。

两条新能力，设计见技术方案 4.9 与 4.10：

- **留言**：录制时同时录声音。放置页把脸种到墙上后点"留言在这里"，app 保存世界地图、一张以放置点为中心的参考图和录制包的副本。首页"留言"列表里点开一条，对准当初的墙面，重定位成功后脸从原处顶出来并播放声音。
- **附近通话**：两台 iPhone 连同一个 Wi-Fi，都打开首页"附近通话"，自动配对。上半屏是对方的 3D 脸种在虚拟砖墙上（可拖动转角度），对方还没连上时同一面砖墙上有一圈缓慢呼吸的暖色光晕标出脸会出现的位置，不再是黑屏；下半屏是自己的前置画面，声音互通。右上角"放到真实平面"切到全屏后置 AR：扫到平面后点网格把对方的脸种在真实的墙或桌上，拖动、旋转、缩放照常；这时前置摄像头只能顺带追踪你的表情，你的贴图停在切换前的最后一帧，所以先在虚拟墙模式让对方收到你的脸再切。

真机验收清单：

| 检查 | 期望 |
|---|---|
| 录制页 | 第一次进入弹麦克风授权；Review 页信息行显示"有声音"，回放有声 |
| 放置后点"留言在这里" | 输入名字后几秒内提示"已保存"；地图没建好时先有一句提醒 |
| 首页"留言" | 条目显示参考图缩略图、名字、"定位：世界地图 + 参考图" |
| 重访（同一时段） | 对准墙面后 1 到 3 秒提示"找到了当初的位置"，脸出现在原处并出声 |
| 重访（换时段 / 光照变化） | 地图对不上时能看到"按参考图找到了位置"，脸位置偏差在几厘米内 |
| 删除留言 | 工具栏垃圾桶 → 确认 → 条目消失，`Application Support/Messages` 下目录被移除 |
| 附近通话配对 | 两台都进页面后几秒内显示"已连接 …"，首次弹本地网络授权 |
| 等待画面 | 进页面就能看到上半屏的砖墙和呼吸光晕，拖动能转角度；对方的脸出现时砖缝不跳位 |
| 对方的脸 | 上半屏出现对方的脸贴在砖墙上，表情和口型跟随，贴图随表情更新，声音能听到 |
| 放到真实平面 | 切换后全屏变成后置画面并出现平面网格，点网格对方的脸种在真实墙面上，表情仍跟随；对方那边你的表情仍在动、贴图定格；切回虚拟墙后贴图恢复更新 |
| 流畅度 | 连上后左上角第二行是统计：收到顶点约 30/s、丢帧个位数百分比、欠载不持续增长、热状态"正常"；对方的脸动作连贯没有顿卡，口型比声音晚不超过约 0.1 秒 |
| 延迟 | 对着对方挥手张嘴，另一台在半秒内跟上 |
| 断开 | 一方退出页面，另一方回到"正在找附近打开了这一页的人…"，再进来能重新连上 |
| 回声 | 同一房间两台外放会啸叫属预期，一方戴耳机验证声音质量 |

已知限制：同房间外放回声；视频比顶点帧慢 100 到 200 ms；参考图识别在纯色墙上会被 ARKit 判为不可用，此时只有世界地图一条路径。

## M2 放置（代码完成，待真机验收）

流程：Face Review → Make your face → 放置页（后置摄像头）→ 点击墙面，脸从墙里凸出来并循环回放表情。右上角"调参"可以实时改淡出带、拉伸、鼓包、鼻尖距离等参数。

录制页改成了原版那样的上下分屏：上半是一面程序生成的砖墙，实时显示当前人脸种在墙上的效果，单指拖动转角度、双指捏合拉远拉近、双击复位，"换墙"可以选相册里的照片；下半是前置摄像头。调参面板和放置页共用，调效果不用先录一段。

真机验收清单：

| 检查 | 期望 |
|---|---|
| 扫描 | 移动手机后墙面、桌面上出现白色半透明网格（10 cm 一格），提示语变成"检测到平面，点击网格放置你的脸"；点击放下后网格消失 |
| 点击墙面 | 脸出现在点击处，+z 朝外，头顶朝上；桌面上放置时头顶朝屏幕上方（一般是远离自己），低头俯视连点几次朝向一致 |
| 手势 | 单指拖动脸沿墙面滑、不离墙；双指旋转脸绕法线转、方向跟手；双指捏合在 0.3 到 3 倍之间缩放；三种可同时做 |
| 调整后留言 | 拖动、旋转、缩放后保存留言，重访时脸出现在调整后的位置、角度、大小 |
| 绕着走 | 脸贴在墙上不漂移；侧看能看到鼻子、嘴唇的起伏，墙后的部分被切掉 |
| 墙纹 | 脸周围的墙纹向外拉伸，过渡带内墙纹盖在脸颊上，和原版砖墙视频一致 |
| 回放 | 表情循环播放，贴图与嘴型同步 |
| 录制页上半 | 脸整个伸出砖墙，鼻尖约 5 cm；额头、下巴被砖纹包住，四周是平滑鼓包，没有空洞和硬边 |
| 调参 | 11 项全部可调，滑杆或 − / + 按钮（每次 0.1 个显示单位）实时生效；记下顺眼的一组值回填 `FaceRenderParameters.standard` |
| 帧率 | Xcode Debug Navigator 里 FPS 接近 60 |

## M0 Spike（已完成）

2026-11-04 在 iPhone 16 上验证完毕，结论已写入技术方案 4.3 与 4.7：

| Spike | 结果 |
|---|---|
| A · 投影烘焙对齐 | 通过。五官对齐无镜像，`flipV = false`，SceneKit 不需额外翻转 |
| B · 前后摄同开 | `userFaceTrackingEnabled` 可用；自开前置 `AVCaptureSession` 会抢走摄像头导致 ARKit 会话失败，方案不可行 |

两个页面保留在工程里作为回归参考，M1 落地后删除。下面是当时的验收说明。

App 启动后是一个菜单，两个 spike 各自回答一个问题。

### Spike A · 投影烘焙对齐验证

回答：按技术方案 4.2 / 4.3 的数学，相机画面能否正确展开到 canonical UV。

操作：进入后对着前置摄像头，看主画面和右下角预览。

| 观察 | 结论 |
|---|---|
| 主画面人脸贴图五官与真人对齐 | 投影矩阵与 `displayTransform` 逆变换正确 |
| 五官左右镜像 | `displayTransform` 方向用反了 |
| 五官整体偏移或缩放不对 | `viewportSize` 与渲染视图不一致 |
| 右下角预览是正立的脸 | 当前 Flip V 设置就是正确的 UV 方向约定，记录下来 |
| 右下角预览倒置 | 点 Flip V 切换，再记录 |

需要记录到技术方案 4.3 的结论：`flipV` 的正确取值，以及 SceneKit 显示 `MTLTexture` 时是否需要额外翻转。

### Spike B · 前后摄同开探针

回答：`ARWorldTrackingConfiguration.userFaceTrackingEnabled` 下，能否再拿到前置画面。

操作：进入后先确认屏幕中央悬浮的黄色线框网格跟着表情动，然后点 Start Front Probe。

| 状态行 | 结论 |
|---|---|
| `probe: running · frames N` 且持续增长 | 方案 B 可行，实时模式可以烘焙贴图 |
| `probe: interrupted · videoDeviceInUseByAnotherClient` | 方案 B 不可行，实时模式按方案 A 规划 |
| `probe: failed · ...` | 记录错误原文 |
| `session: interrupted` 出现在点击探针之后 | 探针把 ARKit 挤掉了，同样视为不可行 |

结论写回技术方案 4.7。

## 目录

```
Faceplant/
├── App/            SwiftUI 入口
├── ARSession/      ARSessionController，唯一持有 ARSession，delegate 跑独立队列
├── FaceMesh/       网格帧、拓扑、blendShape 顺序、FaceMeshSource 协议与实时实现
├── Recording/      .faceplant 包模型、mesh.bin 读写、FaceRecorder、Store
├── Playback/       FaceRecordingPlayer（视频时钟 + 顶点插值）、SceneKit 回放视图
├── Placement/      raycast 结果到脸的世界变换、拖动 / 旋转 / 缩放手势与 FaceAdjustment、AR 放置视图（放置页与通话页共用）
├── Messages/       留言包模型、Store、世界地图 + 参考图抓取
├── Call/           附近通话：Multipeer 会话、消息编码、H.264 编解码、音频播放、远端网格源
├── Rendering/      Metal 烘焙 pass、放置渲染器（背景 + 平面网格 + 脸 pass）、可调参数、像素缓冲纹理缓存、投影数学、共享 shader 类型
├── UI/             Home、Record、Review、Place、留言重访、附近通话页面与调参面板
├── Spikes/         M0 的两个验证页面，M2 后删除
└── Support/        错误类型、二进制读写辅助
```
